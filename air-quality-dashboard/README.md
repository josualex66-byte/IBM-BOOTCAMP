# Global Air Quality Dashboard

Capstone project · Josua · 2026  
An interactive static web dashboard visualising air quality data for 23 000+ cities worldwide.

---

## Quick start

You **must** serve the project through a local HTTP server — browsers block `fetch()` for `file://` paths.

```bash
# Option A — Node.js (npx, no install)
npx serve air-quality-dashboard

# Option B — Python
cd air-quality-dashboard
py -m http.server 8080
# then open http://localhost:8080
```

## Re-running the data pipeline

If you replace `data/global_air_pollution_dataset.csv` with a fresh version:

```bash
cd air-quality-dashboard
py scripts/prepare_data.py
```

`cities.json` will be regenerated.  Dependencies: `pandas` (install with `pip install pandas`).

## Design decisions

- **No backend / no build step** — all processing happens in the browser after a one-time Python pre-processing step that produces compact JSON files (~2.9 MB raw, gzip ≈ 900 KB).
- **Single aggregation pass per filter change** — `aggregate.js` iterates `state.filtered` once per chart function.  Slider changes are debounced (80 ms).
- **Scatter sample cap** — V-05 samples up to 3 000 points to maintain 60 fps rendering.
- **Country ranking threshold** — countries with fewer than 5 cities are excluded from V-02 and V-06 to avoid biased averages.
- **"Unknown" country** — 427 rows without a country code are kept for global statistics but excluded from country-level charts.
- **ISO-3 normalisation** — handled in `prepare_data.py`; a hand-maintained mapping covers all countries in this dataset.
